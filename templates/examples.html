毕业设计格式参考

基于当前加载的格式规范 · GB/T 7714 参考文献标准

一、图片编号 二、脚注格式 三、参考文献

一、图片编号格式

1. 单张图片

图片编号格式为「图X-Y」，X 为章号，Y 为该章内的图序号。图题注居中，{{ caption_size_name }}{{ caption_font }}（{{ caption_size }}pt）。

[图片] 用户增长趋势图

图3-1 短视频平台用户增长趋势图

常见错误
图3.1 短视频平台用户增长趋势图
图3-01 短视频平台用户增长趋势图
错误原因：章号和图序号之间应用短横线「-」连接，不用点号「.」，序号不补零。

2. 同一内容的多张子图

当同一内容有两张或以上图片时，使用子编号：在标题末尾加小写字母（a）（b），用中文括号。图序号不因子编号而增加。

[图片] 美食类封面

图2-1 短视频封面设计示例（a）

[图片] 穿搭类封面

图2-1 短视频封面设计示例（b）

常见错误
图2-1（a）短视频封面设计示例
图2-1(a) 短视频封面设计示例
图2-1A 短视频封面设计示例
错误原因：（a）（b）应放在标题末尾而非紧跟编号；必须使用中文括号（）而非英文括号()；必须使用小写字母而非大写。

3. 子图编号规则

  • 子编号从 （a）开始，连续递增：（a）→（b）→（c）...
  • （a）（b）放在标题文字末尾，不是紧跟图号
  • 至少有 2 张子图时才使用子编号，单独一张图不需要
  • 子图编号不影响主图序号：图2-1（a）（b）之后，下一张整图是图2-2
  • 每个子图都应有独立的图题注，说明该子图内容
    • {% if fig_notes %}
  • 本校补充：{{ fig_notes }}
    • {% endif %}

二、脚注格式

1. 脚注的基本要求

  • 脚注编号按正文中首次引用的顺序排列，从 [1] 开始
  • 同一文献多次引用时，使用同一编号，不重复编号
  • 脚注编号必须与文末参考文献列表顺序一致：脚注 [1] = 参考文献 [1]
  • 脚注格式：{{ footnote_size_name }}{{ footnote_font }}（{{ footnote_size }}pt），英文用 Times New Roman {{ footnote_size_name }}（{{ footnote_size }}pt），单倍行距
    • {% if fn_notes %}
  • 本校补充：{{ fn_notes }}
    • {% endif %}

2. 正文中的脚注引用

正确示例
短视频内容开始垂直细分，穿搭类视频便是短视频内容细分的产物[1]。男装市场规模持续扩大[2]，数字经济下的服装行业也经历着变革[3]。
常见错误
短视频内容开始垂直细分[3]。男装市场规模持续扩大[1]，服装行业经历变革[2]。
错误原因：脚注编号必须按正文中首次出现的顺序递增。先出现的引用编号更小，不能跳号或乱序。同时脚注顺序要和文末参考文献列表的顺序一致。

3. 脚注内容示例（GB/T 7714 顺序编码制）

正确示例
[1] 高彦梅.数字经济时代服装企业商业模式创新研究[J].纺织报告,2025,44(08):46-48.
[2] 艾媒咨询.2006-2025年中国限额以上单位服装商品零售额[R].2025.
[3] Smith J. Digital Fashion Marketing[M]. London: Routledge, 2024.

三、参考文献格式（GB/T 7714）

参考文献采用 GB/T 7714 顺序编码制，编号用方括号 [1][2][3]... 标注。格式为{{ ref_entry_size_name }}{{ ref_entry_font }}（{{ ref_entry_size }}pt），行距固定值 {{ ref_spacing }}pt。要求不少于 {{ ref_min }} 篇，其中外文文献不少于 {{ ref_foreign_min }} 篇。

1. 中文期刊论文 [J]

格式
[序号] 作者.题名[J].刊名,出版年,卷(期):起止页码.
正确示例
[1] 高彦梅.数字经济时代服装企业商业模式创新研究[J].纺织报告,2025,44(08):46-48.
常见错误
[1] 高彦梅.数字经济时代服装企业商业模式创新研究.纺织报告,2025,44(08):46-48.
错误原因：缺少文献类型标识 [J]。期刊论文必须标注 [J]。

2. 中文专著 [M]

格式
[序号] 作者.书名[M].出版地:出版社,出版年:引用页码.
正确示例
[5] 彭兰.新媒体用户研究[M].北京:中国人民大学出版社,2023:56-78.

3. 学位论文 [D]

格式
[序号] 作者.题名[D].保存地:保存单位,年份.
正确示例
[8] 张三.短视频平台内容生态研究[D].南昌:江西师范大学,2024.

4. 网络文献 [EB/OL]

格式
[序号] 作者.题名[EB/OL].(发布日期)[引用日期].URL.
正确示例
[12] 中国互联网络信息中心.第53次中国互联网络发展状况统计报告[EB/OL].(2024-03-22)[2025-05-01].https://www.cnnic.net.cn/.
常见错误
[12] 中国互联网络发展状况统计报告 https://www.cnnic.net.cn/
错误原因：缺少 [EB/OL] 标识、发布日期和引用日期。网络文献必须标注完整的可追溯信息。

5. 英文期刊论文

格式
[序号] Author A, Author B. Title[J]. Journal Name, Year, Vol(No): Pages.
正确示例
[3] Smith J, Wang L. Social media marketing in fashion industry[J]. Journal of Fashion Technology, 2024, 15(3): 45-52.

6. 英文专著

格式
[序号] Author. Title[M]. Place: Publisher, Year: Pages.
正确示例
[15] Kaplan A M, Haenlein M. Digital Marketing[M]. New York: McGraw-Hill, 2023: 112-135.

7. 格式速查表

文献类型 标识 正确格式 常见错误
期刊论文 [J] 作者.题名[J].刊名,年,卷(期):页码. 漏标 [J]；缺少卷期号
专著 [M] 作者.书名[M].出版地:出版社,年:页码. 漏标 [M]；缺少出版地
学位论文 [D] 作者.题名[D].保存地:保存单位,年. 漏标 [D]；缺少保存单位
网络文献 [EB/OL] 作者.题名[EB/OL].(发布日)[引用日期].URL. 漏标 [EB/OL]；缺日期或URL
报告 [R] 作者.题名[R].出版地:出版者,年. 漏标 [R]
关键规则：① 每条参考文献必须有文献类型标识；② 编号格式统一使用 [序号]；③ 作者超过 3 人写前 3 人后加"等"或"et al"；④ 英文作者姓在前名缩写在后，如 Smith J。
